# RPS_Game
# Rock Paper Scissors AI

This project is part of the Machine Learning certification.

## Description

Built an AI agent that plays Rock-Paper-Scissors and adapts to opponent strategies using pattern detection and frequency analysis.

## Features

* Predicts opponent moves based on history
* Uses multiple strategies (pattern + frequency)
* Achieves >60% win rate against all bots

## How to run

Run main.py to test the bot:
python main.py
